# StreamSuites Creator v0.5.4-alpha

**Release date:** 2026-07-26

## Scope

This changelog documents creator-facing content and publishing behavior for v0.5.4-alpha as a documentation correction pass. Client behavior and publish capabilities remain governed by canonical runtime and auth services.
